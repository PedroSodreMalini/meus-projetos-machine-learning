# Bagging Regressor - Predição de Gastos de Saúde de Funcionários

## Resumo
Uma Health-Tech deseja predizer os valores ofertados para os seus funcionários com plano de saúde.

## Dataset
|Variável|Tipo|Significado|
|:-:|:-:|:--|
|age|int|Idade do funcionário|
|sex|str|Sexo do funcionário|
|bmi|float|Índice de Massa Corporal (IMC)|
|children|int|Número de filhos do funcionário|
|smoker|str|Se o funcionário é fumante ou não|
|region|str|Região que o funcionário mora|
|medical charges|float|**Target:** Gastos com saúde do funcionário em 2 anos|
